## 湖南博物院马王堆汉墓经典展品介绍

### 一、马王堆汉墓概述

长沙马王堆汉墓是20世纪世界最重大的考古发现之一。1972至1974年间，考古工作者在长沙市东郊发掘了三座西汉墓葬，墓主为西汉长沙国丞相、轪侯利苍及其夫人辛追、儿子利豨。三座墓葬共出土三千多件珍贵文物，包括保存完好的丝织衣物、工艺繁复的精美漆器、逾五十篇“百科全书”式的简帛文献以及诡谲奇幻的彩棺帛画，为人们了解2200年前的社会风貌打开了一扇窗口。据最新整理数据，马王堆汉墓共出土文物26937件，其中漆木器1017件（869件保存完整），是迄今各地发现汉代漆器中数量最多、保存最好的一批。

### 二、镇馆之宝：T形帛画

T形帛画出土于马王堆一号汉墓，覆盖在墓主人辛追夫人的内棺盖上，整幅画长逾2米（通长205厘米，上部宽92厘米，下部宽47.7厘米），出土时顶端横一根竹竿并系以丝带，下部四角各缀一条麻穗。因外形呈“T”字形而得名，是湖南博物院的“镇馆之宝”之一。

这幅帛画属于墓葬美术范畴，在西汉被称为“非衣”，古人认为它是墓主人灵魂升天的媒介。画作以笔墨和重彩绘制，凝聚了汉代人对地府和仙境的想象，从下到上分为地下、人间和天上三个部分：

- **天上部分（T形上端最开阔处）** ：描绘人首蛇身的天帝统御苍穹，金乌振翅的日轮与蟾蜍、玉兔栖息的月宫相对，还有扶桑树和八个小太阳散布其间，呈现宁静和谐的仙界图景。
- **人间部分**：以玉璧为界划分上下两层。上层描绘墓主人升天的场景，辛追夫人身着华服、拄拐杖，在三位侍女簇拥下缓缓升天；下层描绘对她的祭祀场景，有帷帐、庭堂及饮食器皿。
- **地下部分**：描绘赤足巨人脚踏鲸鲵、双掌托起大地的幽冥景象。

近期，湖南博物院通过多模态图像信息采集手段，首次发现T形帛画上有多处改绘痕迹：天上部分守门神手中的玉圭只留下了底稿痕迹，门吏边的豹子改变了位置，人间部分祭祀墓主人的人员数量也有所增加。专家推测，可能是T形帛画准备时间较早，到辛追夫人去世时礼仪已发生改变所致。

T形帛画将神话、想象和世俗世界融会于一张图上，凝聚了汉代人对宇宙和生命的想象与理解，代表了整个马王堆墓葬的精神核心。

### 三、举世闻名的素纱单衣

马王堆一号汉墓出土了两件素纱单衣，一件为直裾式（49克），另一件为曲裾式（48克）。曲裾式素纱单衣衣长160厘米、通袖长195厘米，共用纱料约2.6平方米，整件衣物重量仅有48克，约等于一个鸡蛋的重量，是世界上现存年代最早、保存最完整、厚度最薄、重量最轻、制作工艺最精湛的丝织衣物，被誉为西汉时期纺织技术的巅峰之作。直裾式素纱单衣衣长128厘米、通袖长190厘米，共用料约2.6平方米，仅重49克，折叠后甚至可以放入火柴盒中。

“素纱”指没有染色的纱，“单衣”指没有衬里的衣服，准确的名称应为“素纱襌衣”。两件单衣均为交领、右衽，是典型的汉服领型。经测算，其透空率约为75%，每平方米纱料仅重15.4克。蚕丝纤度只有10.2至11.3旦，比现在生产的高级丝织物（14旦）还要细，足见汉代缫纺蚕丝技术的高度发展。

关于穿着方式，多数学者认为素纱单衣穿于锦绣外衣之上，以轻薄素纱罩于华服之外，使纹饰若隐若现，既增添层次感，又衬托出锦衣的华美与尊贵，符合中国人含蓄内敛的传统审美情趣。

### 四、千年不腐的辛追夫人遗体

辛追夫人是西汉长沙国丞相、轪侯利苍的妻子，去世时年约50岁，其生活年代距今2200多年。1972年，辛追遗体出土于马王堆一号墓内棺，出土时身高1.54米、体重34.3公斤。虽在地下沉睡了2100多年，但外形保存完整，全身润泽，皮肤覆盖完整，毛发尚在，指、趾纹路清晰，肌肉尚有弹性，部分关节可以活动，是世界上首次发现保存如此完好的历史悠久的湿尸，被誉为“世界上保存时间最长的湿尸”。

辛追遗体目前由湖南博物院保存在模仿当年出土原状修建的地下寝宫中。该地下寝宫距离地面8米，恒温恒湿，置放着大型棺椁，周围还有墓坑模型，接近辛追当年沉睡两千多年的原始地下环境。

### 五、精美绝伦的汉代漆器

马王堆汉墓出土了700多件精美漆器，代表了汉初漆工艺发展的最高水平。其中最具代表性的展品包括：

**（一）“君幸食”彩绘狸纹漆盘。** 马王堆三号墓出土，口径28.5厘米、高6厘米。盘内中心绘一只狸猫，用朱漆绘眼、耳、爪、尾花纹。猫两眼圆睁，两耳竖立，蹲踞于地，长尾垂地，形象生动可爱。盘内底中心猫纹右上方用朱漆书“君幸食”三字，意为“请您吃好”；口沿背底书“九升”为容量单位（汉代1升约合今200毫升）。狸猫纹在其他墓葬及史料文献中均无记载，是马王堆汉墓独有的纹样。

**（二）锥画狩猎纹夹纻胎漆奁。** 马王堆三号墓出土，通高17.2厘米、口径28厘米。器身分上下两层，连盖共三部分，外髹黑漆、内髹红漆。整器采用锥画工艺，在漫卷的流云中刻有奔跑的小兔、自在的游鱼、飞翔的凤鸟等图案，主要部位为神人骑兽遨游和一幅生动有趣的狩猎图——猎人持矛奋力追赶奔鹿，形象逼真传神，显示出汉代漆器锥画工艺的高超技巧。器表还留有“成市草”（成都制造）等产地标识戳记。出土时奁内放置丝带、假发及带孔骨器等梳妆用具，印证其化妆容器的功能。

**（三）彩绘双层九子漆奁。** 马王堆一号墓出土的妆奁精品。器身分上下两层，连盖共三部分。器表髹黑漆，漆上贴金箔，以金、白、红三色油彩绘云气纹。下层底板凿出九个凹槽，放置九个小奁，分别为椭圆形2件、圆形4件、马蹄形1件、长方形2件。小奁内放置白色颜料、丝绵、假发、胭脂、木梳篦等化妆品。九子奁在圆形漆盒中作了巧妙排列，既节省空间又美观协调，表明汉代漆奁盛装物品的功能已十分完备，越发贴近日常生活。

### 六、马王堆汉墓的其他重要发现

除上述明星展品外，马王堆汉墓还出土了：五百多件织精绣美的丝织衣物，采用印染、印花、彩绘、刺绣等工艺制成，印证了西方文献中东方“丝国”的记载；逾五十篇涵盖哲学、政治、军事、天文、地理、医学等领域的简帛文献，堪称“千年前的地下图书馆”；以及“利苍”玉印、“长沙丞相”铜印、“轪侯之印”铜印等证实墓主身份的重要文物。

湖南博物院三层的“长沙马王堆汉墓陈列”展示面积5243.8平方米，分为序厅及惊世发掘、生活与艺术、简帛典藏、永生之梦四个单元，参观时间约需1.5小时。观众可通过湖南博物院微信公众号或支付宝小程序预约参观，开放时间为周二至周日9:00-17:00（16:00停止入馆），周一闭馆。
